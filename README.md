## 项目简介

本仓库包含**人工智能训练师（三级）操作技能考核**的完整离线模拟环境，并在原始题库基础上扩展了两套自动判分工具：

| 模块 | 文件 | 用途 |
|------|------|------|
| 原始题库 | `试题主页面.html` + `files/` | 浏览器打开即可模拟真实考试页面 |
| **在线答题页面** | `答题页面.html` | 编程题直接在网页空格里填答案，点"判分"即时对错；写作题文本框作答 + 关键词对照 |
| **自动对答案系统** | `对答案.bat` + `对答案系统/` | 在 Jupyter 里做完题后一键核对：运行参考代码、逐行比对输出、检查交付文件、生成评分报告 |
| 参考答案 | `人工智能训练师三级操作题答案最新/` | 40 道题的官方参考答案（含评分细则） |

### 题型分布

| 类型 | 数量 | 题号 | 判分方式 |
|------|------|------|----------|
| 编程题 | 19 | 1.1.x、2.1.x、2.2.x、3.2.1~3.2.4 | 自动（填空比对 / 输出比对） |
| 写作题 | 21 | 1.2.x、3.1.x、3.2.5、4.x | 关键词覆盖 + 对照参考答案自评 |

## 功能特性

### 1. 在线答题页面（`答题页面.html`）

- **免 Jupyter、免 Python、完全离线**，双击即用
- 编程题：把 ipynb 模板中的下划线空格转换成网页输入框，**263 个填空的标准答案**全部自动提取并内嵌（Base64 编码，不点"显示答案"不可见）
- 点击"判分"：每空立即 ✓/✗，按评分细则折算**估算得分**
- 写作题：文本框作答，一键"关键词对照"（绿色=已覆盖/灰色=未覆盖）、"显示参考答案"
- 答题进度**自动保存在浏览器 localStorage**，关闭页面不丢失
- 顶部统计面板（已作答数 / 判分数 / 正确率 / 估算总分），支持按章节筛选
- 判分容错：自动忽略空格差异、中英文引号（`'` `"` `‘` `’`）、全角括号（`（）`）

### 2. 自动对答案系统（`对答案.bat`）

模拟真实考试流程（Jupyter 做题）后的自动阅卷：

- **自动运行参考代码**：从答案 docx 提取 Python 参考代码（自动修正原文档中的笔误），在隔离目录实跑获得标准输出
- **逐行比对输出**：读取你 ipynb 中保存的运行结果，有数字的行按数字比对（容差 1e-6），纯文本行按整行匹配
- **交付文件检查**：按题目要求核对截图 JPG、导出 HTML、docx 等文件是否齐全、命名是否正确
- **智能状态识别**：未作答 / 已填码未运行 / 有空未填 / 有报错（FutureWarning 等警告自动忽略）
- **评分报告**：生成 `对答案报告.html` 并自动打开，含总览表、逐题详情、评分细则、参考代码
- **结果缓存**：参考代码运行结果按（代码+素材）哈希缓存，第二次起秒出报告

### 3. 防误判细节

- ipynb 中仍有 ≥6 个连续下划线 → 判定"有空未填"，得分记 0（防止模板自带的示例输出骗分）
- 直接在 `files/素材/` 里作答也能被检测（无需复制到指定文件夹）
- 参考代码笔误自动修补：2.1.4（`plot(fontproperties=...)` 与 `plt.scatter(figsize=...)`）、2.2.2（`with` 块缩进）、3.2.3（已废弃的 `Image.ANTIALIAS` → `Image.LANCZOS`）

## 快速开始

### 方式一：在线答题（最简单，推荐日常刷题）

1. 双击 `答题页面.html`（Chrome / Edge 均可）
2. 展开题目卡片，直接在代码空格中输入答案
3. 点击 **判分** → 查看对错与估算得分
4. 不确定时点 **显示答案** 核对；想看程序应输出什么点 **参考输出**

> 答题内容自动保存在浏览器中。换浏览器或清缓存后丢失。

### 方式二：完整考试流程模拟（推荐考前演练）

1. **启动 Jupyter**：终端执行 `jupyter notebook`，进入 `files/素材/题号/` 打开 ipynb
2. **作答**：只在下划线处补全代码 → 运行全部单元格 → `Ctrl+S` 保存
3. **归档**：把 ipynb 和截图等交付文件复制到 `我的作答/题号/`
4. **对答案**：双击 `对答案.bat` → 自动生成 `对答案报告.html` 并打开浏览器

## 使用方法

### 答题页面详细说明

| 按钮 | 作用 |
|------|------|
| 判分 | 比对所有空，显示 ✓/✗、正确数、估算得分 |
| 显示答案 | 列出全部标准答案（可展开完整参考代码） |
| 参考输出 | 显示参考代码在本机实跑的标准输出 |
| 重置本题 | 清空本题输入（含浏览器存档） |

写作题按钮：**关键词对照**（覆盖高亮）、**显示参考答案**、**清空**。

顶部统计卡：已开始作答 / 编程题已判分 / 填空正确率 / 编程题估算总分。
章节筛选：全部 / 第1~4章。

### 对答案系统详细说明

作答文件放置约定：

```
我的作答/
└── 1.1.1/
    ├── 1.1.1.ipynb      # 运行并保存后的 ipynb（或直接在素材文件夹作答）
    ├── 1.1.1-1.jpg      # 题目要求的截图
    ├── 1.1.1-2.jpg
    ├── 1.1.1-3.jpg
    └── 1.1.1.html       # Jupyter 导出的 HTML（File → Save and Export → HTML）
```

评分报告内容：

- **总览表**：40 题状态（未作答 / 已作答 / 有报错 / 有空未填）与得分
- **逐题详情**：预期输出 vs 你的输出（✓/✗ 逐行着色）、交付文件清单、报错信息、参考代码、评分细则表
- **估算口径**：按"匹配到的输出行数 / 总行数 × 满分"折算，不含文件保存规范类评分项

### 重新生成答题页面

题库或答案更新后（或删除了 `模板快照/`），重新生成：

```bash
python 对答案系统/生成答题页面.py          # 生成 答题页面.html
python 对答案系统/生成答题页面.py --selftest  # 仅检查答案对齐情况
```

## 工作原理

### 答案自动提取与对齐（生成答题页面.py）

1. **参考代码提取**：解析答案 docx 的 `word/document.xml`，定位"参考答案："之后的代码段，用启发式规则（中文起始行、全角括号、文件名格式等）剥离代码后附带的文字说明，`compile()` 校验语法
2. **模板读取**：优先读 `模板快照/`（原始模板），否则用素材文件夹或 Jupyter checkpoint 中未被编辑过的副本——避免做题时填入的内容污染答案提取
3. **多级对齐算法**：把模板中每个下划线空（`_{4,}`）转为捕获组，与参考代码逐行匹配：
   - Tier 1 原文全行匹配 → Tier 2 两侧去注释 → Tier 3 前缀匹配（容忍尾部多参数）
   - Tier 4 弹性空格（字符间 `\s*`，解决 `>7` vs `> 7`）→ Tier 5 截断锚点
   - 预处理：合并续行（`&` 结尾 / 括号未闭合）；非空模板行占用对应参考行，防止空行向上错位
   - 个别参考代码与模板结构不一致处（如 2.2.3 改为 `from xgboost import`）用手工答案表兜底
4. 19 道编程题 **263 个空全部对齐成功**，抽验答案正确

### 判分逻辑

- **答题页面**：输入值与标准答案做规范化比对（去空白、统一引号、全角括号转半角）
- **对答案系统**：参考代码经补丁修正后在隔离目录实跑 → 提取 stdout 与用户 ipynb 保存的输出 → 有数字行按数值比对（相对容差 1e-6）、无数字行按整行文本匹配 → 按评分细则满分折算估算分

### 缓存机制

参考代码运行结果缓存于 `对答案系统/缓存/manifest.json`，键为（补丁后代码 + 素材数据文件）的 MD5。素材或答案变更后自动重跑。

## 常见问题 FAQ

**Q1：答题页面显示我答错了，但我的写法应该也对？**
判分按参考答案比对，等价写法（如 `shape[0]` vs `len(data)`）会被判错。点"显示答案"核对即可；需要真跑验证请用对答案系统（它比对的是运行结果而非代码文本）。

**Q2：对答案报告显示"未作答"，但我明明运行过？**
确认在 Jupyter 中按过 `Ctrl+S`（输出会存入 ipynb），且文件位于 `我的作答/题号/` 或 `files/素材/题号/`。

**Q3：`jupyter` 命令找不到？**
未安装依赖：`pip install -r requirements.txt`。注意系统里若有 Windows 商店的假 python，请确认 `python -m pip` 指向真实安装。

**Q4：参考代码运行失败？**
删除 `对答案系统/缓存/` 后重试。若仍失败，检查依赖是否装全（尤其 onnxruntime、xgboost）。

**Q5：做完题后重新生成答题页面，答案对不上了？**
正常现象——答案提取依赖原始模板。`模板快照/` 已保护原始模板；若你删除过快照且素材被编辑，从 Jupyter checkpoint 或原始题库恢复模板后重新生成。

**Q6：3.2.3 题目模板自带了示例输出，会被算分吗？**
不会。检测到模板仍有未填空时按 0 分处理并提示"有空未填"。

**Q7：想把作答进度换台电脑保留？**
答题页面进度存在浏览器 localStorage，可用浏览器同一账号同步；或改用 Jupyter 流程（文件可拷贝）。
